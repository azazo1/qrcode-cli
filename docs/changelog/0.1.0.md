# qr v0.1.0

Date: 2026-11-11

首个发布版本: 一个零运行时依赖的二维码编解码命令行工具.

## Highlights

- 解码支持一张图内的多个二维码, 按阅读顺序全部列出.
- 编码可在终端用半块字符高密度显示, 终端放不下时自动改用浏览器.
- 输入来源覆盖命令行参数, 管道与系统剪贴板, 无子命令时自动判定解码还是编码.

## Features

- 解码: 一张图里的多个二维码会全部识别并按阅读顺序 (从上到下, 从左到右) 编号输出, 也可用 `--json` 取得包含位置与纠错等级的结构化结果.
- 解码: 输入来源可以是图片文件, 管道或系统剪贴板, 复制截图后直接运行即可得到内容.
- 编码: 终端用半块字符绘制二维码, 一个字符格表示两行模块, 显示尺寸因此只有模块数的一半行数.
- 编码: 二维码放不进当前终端时自动启动本地网页服务, 在浏览器里显示完整二维码, 服务常驻到按 Ctrl+C.
- 自动模式: 不带子命令时按输入内容判定, 是图片则解码, 是文本则编码, 不必记住子命令.
- 日志: 每次调用都会说明读取了什么, 按什么模式处理, 结果写到哪里, 来源与模式一目了然.

## Upgrade Notes

1. Linux 上读取剪贴板需要 Wayland 合成器支持 data-control 协议. 老版本合成器不提供该协议时, 剪贴板会退回到 XWayland, 因此还需要 X server 可用; 其余输入来源不受影响.
